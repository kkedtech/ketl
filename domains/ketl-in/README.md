# ketl-in

GitHub Pages site for **ketl.in**. Every page (including unknown paths, via
`404.html`) forwards visitors to https://ketl.au/in/, keeping any query
string such as `?utm_source=flyer`.

The main website lives in the `ketl` repository (served at ketl.au). GitHub
Pages allows only one custom domain per repository, which is why ketl.in
has this separate repository.
