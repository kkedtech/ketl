How it works

What they'll actually build.

They won't just prompt AI. They'll learn what it's built on. Real projects, real code, real systems.

Explorer

Days 1–2: Understand how AI learns. Block-code a machine learning classifier. First real functions, first real logic.

Partner

Days 2–4: Configure AI as a working partner. Integrate an API. Code against a real system, not a sandbox.

Architect

Day 5: Put it together. Build a small tool that does something useful. Portfolio piece. Proof they understand the stack.
